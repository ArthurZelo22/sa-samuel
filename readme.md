# TekkoKoala 🐨
 
Projeto acadêmico de loja virtual de gadgets e eletrônicos.
 
## Sobre o projeto
 
A TekkoKoala é uma loja virtual de gadgets modernos que nasceu para descomplicar a tecnologia com leveza e carisma. Inspirados na tranquilidade do coala, oferecemos eletrônicos de ponta através de uma experiência de compra simples, rápida e totalmente sem estresse.
 
O projeto foi idealizado pelos fundadores Arthur Tavares, Bruno, Eduardo Vieira, Ravi e Joaquin com foco total na experiência do usuário: catálogo intuitivo de produtos, navegação fluida e transparência em todas as etapas do carrinho e do fechamento de pedido.
 
**Por que um coala?**
- **Calma e Tranquilidade:** o coala representa o compromisso da marca em descomplicar a tecnologia, permitindo comprar sem estresse.
- **Equilíbrio com o "Tekko":** enquanto "Tekko" remete à inovação e modernidade dos produtos eletrônicos, o "Koala" traz a leveza, o carisma e a simplicidade humana no atendimento.

## Páginas do site
 
- **Início** — Catálogo de produtos, carrinho de compras e formulário de dados para entrega.
- **História** — Apresenta a origem da loja, os fundadores e o conceito por trás da marca/mascote.
- **Contatos** — Exibe os cartões dos três fundadores/desenvolvedores do projeto, com foto, nome e usuário de contato (Instagram).

## Requisitos Funcionais
- **RF01** — O sistema deve exibir uma lista/catálogo de produtos, contendo imagem, nome e preço de cada item.
- **RF02** — O sistema deve permitir adicionar produtos ao carrinho de compras através do botão "adicionar ao carrinho".
- **RF03** — O sistema deve exibir o carrinho de compras com os itens adicionados, ou uma mensagem informando que o carrinho está vazio.
- **RF04** — O sistema deve calcular e exibir o **subtotal** da compra com base nos itens do carrinho.
- **RF05** — O sistema deve calcular e exibir o **total** da compra, aplicando descontos quando cabível.
- **RF06** — O sistema deve permitir o envio do pedido através do botão "Enviar".
- **RF07** — O sistema deve permitir a navegação entre as páginas Início, História e Contatos através do menu superior.
- **RF08** — O sistema deve permitir a alteração da cor de fundo do site através do botão "Cor de fundo".
- **RF09** — O sistema deve exibir, na página Início, uma breve descrição institucional da loja.
- **RF10** — O sistema deve exibir, na página História, o texto sobre a origem da loja e o conceito do mascote.
- **RF11** — O sistema deve exibir, na página Contatos, os cartões dos fundadores/desenvolvedores contendo foto, nome e usuário de contato


## Requisitos Não Funcionais
- **RNF01 — Usabilidade:** a interface deve ser simples, intuitiva e de fácil compreensão, permitindo que o usuário conclua a compra sem etapas desnecessárias.
- **RNF02 — Responsividade:** o layout deve se adaptar a diferentes tamanhos de tela (desktop, tablet e mobile).
- **RNF03 — Desempenho:** as ações de adicionar ao carrinho e recalcular o total devem ocorrer de forma imediata.
- **RNF04 — Identidade Visual:** o sistema deve manter consistência visual em todas as páginas.
- **RNF05 — Acessibilidade/Personalização:** o sistema deve permitir customização visual básica (ex.: alteração de cor de fundo) sem comprometer a legibilidade do conteúdo.
- **RNF06 — Compatibilidade:** o sistema deve funcionar corretamente nos principais navegadores web.
- **RNF07 — Manutenibilidade:** o código deve ser organizado de forma a facilitar a manutenção e a adição de novos produtos/páginas.


## Regras de Negócio
- **RN01** — O subtotal da compra é calculado pela soma dos preços de todos os produtos adicionados ao carrinho.
- **RN02** — É concedido um desconto de **10%** sobre o valor total em compras acima de **R$ 1.000,00**.
- **RN03** — O valor total exibido deve refletir o subtotal já com o desconto aplicado (quando houver).
- **RN04** — O carrinho deve exibir o valor "R$ 0,00" tanto no subtotal quanto no total quando estiver vazio.
- **RN05** — Os campos "Nome completo" e "E-mail" do formulário de entrega são de preenchimento obrigatório para o envio do pedido.
- **RN06** — O campo "E-mail" deve ser validado quanto ao formato correto de endereço eletrônico antes do envio.
- **RN07** — O pedido só pode ser enviado ("Enviar") caso o carrinho contenha pelo menos um produto.
